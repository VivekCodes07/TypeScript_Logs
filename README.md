# TypeScript Logs

This repository contains my personal notes, examples, experiments, and practice code while learning **TypeScript**.

I am following **Hitesh Choudhary's TypeScript course** as my main course, and I am studying each topic in more depth with **ChatGPT**.

I am not trying to master every advanced feature of TypeScript right now.

My main goal is to learn enough TypeScript so that I can comfortably use it while building **Node.js and backend applications**.

# My Learning Goal

I am learning TypeScript because I want to use it with my backend stack.

My overall path is:

```text

    ↓
Node.js + TypeScript
    ↓
Express + TypeScript
    ↓
MongoDB + TypeScript
    ↓
REST APIs
    ↓
Authentication
    ↓
Validation
    ↓
Error Handling
    ↓
Real Backend Projects
```

I want TypeScript to become a tool that helps me write better backend code instead of something I have to constantly fight with.

So while learning, I focus on:

* Understanding the type system
* Understanding why TypeScript behaves the way it does
* Writing type-safe JavaScript
* Understanding common TypeScript patterns
* Knowing where a feature is useful in real projects
* Being comfortable reading TypeScript code written by other developers

I will learn deeper TypeScript concepts later when a real project gives me a reason to use them.
